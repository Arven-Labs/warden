# What isn't verified yet

An honest note about the stage the project is in: it has many automated tests, but several features have only
run against a fake model. If something odd shows up, it's likely to be here: **skills, scheduled tasks,
delegation between agents, image attachments, voice and read-aloud**, nodes on different machines and the
**iPhone app**.

Each one is tracked in the project's `PENDING.md` in the
[repository](https://github.com/Arven-Labs/warden/tree/main/project). If you find a defect, write down what
you did and what you expected.
